# Dark Soul - Jeu Roblox Complet

Ce projet est un jeu Roblox complet inspiré de Dark Souls.

## Fonctionnalités
- **Combat** : Au corps à corps (clic gauche) et magie (clic droit).
- **Armes** : Épée, Hache, Dague avec stats différentes.
- **Santé & Régénération** : Lente, comme Dark Souls.
- **Niveaux & Exp** : Gagner exp en tuant ennemis, level up augmente santé.
- **Inventaire** : Potions, sorts, armes.
- **Ennemis & Boss** : Difficiles, avec phases.
- **UI** : Affichage santé, inventaire.

## Contrôles
- Clic gauche : Attaquer.
- Clic droit : Lancer sort (Fireball).
- E : Utiliser potion.
- Mouvement : WASD.

## Structure
- `ServerScriptService/` : Logique serveur.
- `StarterPlayer/StarterPlayerScripts/` : Contrôles client.
- `ReplicatedStorage/` : Modules partagés.

Importez dans Roblox Studio pour jouer !
