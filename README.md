# Dark Soul - Jeu Roblox Ultra-Complet

Ce projet est un jeu Roblox ultra-complet inspiré de Dark Souls.

## Fonctionnalités
- **Combat** : Au corps à corps (clic gauche) et magie (clic droit).
- **Armes** : Épée, Hache, Dague, Greatsword, Bow (avec stats variées).
- **Santé & Régénération** : Lente, comme Dark Souls.
- **Niveaux & Exp** : Gagner exp en tuant, level up, perte à la mort.
- **Inventaire** : Potions, sorts, armes, avec UI détaillée.
- **Quêtes** : Tuez ennemis pour récompenses (PNJ donne quêtes).
- **Zones** : Zone 1 et Zone 2 (téléporteur vert).
- **Sauvegarde** : Persistance niveau/exp/inventaire.
- **Ennemis & Boss** : Difficiles, phases, variés.
- **UI** : Santé, niveau, inventaire, quêtes, bouton inventaire.

## Contrôles
- Clic gauche : Attaquer.
- Clic droit : Lancer sort.
- E : Utiliser potion.
- Bouton "Inventaire" : Ouvrir menu détaillé.
- Mouvement : WASD.

## PNJ & Zones
- PNJ bleu : Touchez pour quête (tuer 5 ennemis).
- Téléporteur vert : Vers Zone 2 avec boss plus dur.

Importez dans Roblox Studio pour jouer !
